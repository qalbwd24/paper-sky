# 风过纸翼

新增独立的 [四人联机追逐版](online/README.md)：运行 `node online/server.cjs` 后打开 http://127.0.0.1:8770/chase/ 。房主指定追击机，10 米内锁定 1.5 秒自动发射导弹；命中后交换身份，被捕获者回到起点。支持独立皮肤、捕获/被捕获计数、Shift 加速、Ctrl 减速和断线重连。云端安装方式见 [部署交接](online/DEPLOY.md)，本地交付不代表云端已安装。

一个本地、离线的轻量三维纸飞机游戏。双击 `启动游戏.cmd` 即可玩；启动器使用已有的 Node.js，只监听本机，重复启动会复用服务。无需建模软件或联网。

## 小东京街区

启动服务后打开 [小东京街区](http://127.0.0.1:8768/tokyo.html)，或在原游戏顶部点击“小东京街区”。这是保留 Littlest Tokyo 原始材质和动画的独立试飞场景，提供三个起点、“原作材质 / 柔和插画”切换与街区俯瞰。Ctrl 慢飞，Shift 加速，空格起飞或碰撞后重飞。模型已保存在本地，署名与许可见 `assets/littlest-tokyo/来源与许可证.md`。详细变化见《小东京接入说明.md》。

## 本次更新：五层迷境

五层分别随机生成自己的节点、路线与物件：砂谷分岔、水墨环廊、机械网格、错层纸城、晶洞群岛。每层约 **1.68 × 1.68 公里**；层高依次为 **312 / 408 / 342 / 456 / 378 米**。顶部选择“五层迷境”，可直接选层、查看三维布局图，或点“重排迷境”重新生成。

换层有 **4 条不同形状的缓坡航道 + 4 组双向折跃捷径（8 个门）**。航道方位、形状细节和折跃门连接随种子变化。折跃门上有目的地标牌，小地图用紫点标记；穿过后直接移动到对应层，保留速度和姿态。没有直升风柱。默认布局的实体航道约 2.7–4.1 公里，最大坡度约 7°，也能反向下滑。

迷境普通滑翔巡航约 61 m/s，Shift 约 132 m/s，主动俯冲加速可接近 150 m/s；Ctrl 仍适合穿窄洞。非加速俯冲峰值为 68 m/s。加速时转弯角速度约 117°/s（平时约 43°/s），最大机翼倾斜约 52°，最大仰角 25°；松开 Shift 后平滑恢复普通操控。只有迷境提高巡航和高速操控。所有场景起飞改为低速：室内 0.8 m/s，室外与迷境 8 m/s，前三秒逐渐恢复巡航与自然下沉。按 Shift 可主动加速。

空格优先回到较早的开阔航段，并检查接近三秒的起飞轨迹。角落没有出路，或重飞后四秒内又撞墙时，回到本层安全起点。默认画质为“清晰 · 顺滑”，动感为“柔和”。

清除了廊墙重叠、楼板与立柱重合面，以及叠加轮廓造成的闪烁风险。翼尖细气流改为在镜头附近计算浮点坐标；清晰画质的动感后处理使用 4 倍多重采样。原有固定 120 Hz 物理、渲染插值与平滑镜头继续保留。

空间说明见《迷境空间设计.md》。原教室、山谷、三重中庭及三种皮肤继续可选。

## 场景与皮肤

顶部可以随时选择：

- **三重中庭**：3 层 × 16 × 16 米，层高 5 米；单层面积约为教室的 2.93 倍。一层为暖色旧车站，二层为水墨庭院，三层为深色霓虹实验室。中间 6 × 6 米的开口贯通三层。

- **高中教室**：约 8.4 × 10.4 × 3.6 米，42 张课桌、木椅、黑板、讲台、窗帘、玻璃窗、吊扇、日光灯、书本和水杯。尺寸为建模近似值，参考资料见 `references/README.md`。
- **晴湾山谷**：保留原来的河流、村落、风车、树木和远山。
- **方格纸 · 数学草稿**：函数、导数、数列、三角恒等式和手绘图。
- **方格纸 · 考研机械**：四杆机构、自由度计算、齿轮、轴系结构草图。
- **素白纸**：保留没有笔迹的纸飞机。

飞机采用 A4 纸折叠后的近似尺度：长 18.6 厘米，翼展 12.6 厘米。重建了尖头、两翼和中间折痕，尖头与前进方向一致。飞机和教室共用米制尺度；镜头靠近跟随，小窗口适当后移，兼顾真实比例与可见性。切换场景回到对应起点；切换皮肤不重置飞行。场景和皮肤选择保存在当前浏览器的本地存储中。

## 三重中庭怎么玩

从一层出发，飞向中间有上升风线和环形标记的区域。进入左侧气流后，按住 **Ctrl + J 或 L** 慢飞盘旋，就能逐渐升到上层；到合适高度后松开转弯键，飞出中庭进入楼层。右侧气流较弱，可以俯冲下降；主动俯冲也会减弱托举，避免被困在上升气流里。

顶部的“起点楼层”可以直接从任意一层重新开始。每层走道上都有安全落脚区，大片地面可以降落。随机物件主要成组分布在边缘，保证至少七成空地，并避开 2.7 米宽的贯通走道、中庭开口和主要落脚区。当前默认种子按模型占地估算约有 89% 空地。

点击“换一种布局”会重新生成三层的零散物件并回到所选起点，楼层风格和主要建筑保留。种子保存在浏览器本地，普通刷新不会改变布局；飞行途中也不会突然出现新障碍。

三种画风使用简单几何、批量绘制和程序化窗景，霓虹不依赖高成本的全屏泛光。远隔一层的细节物件会停止绘制，楼板和主体结构仍可见。三重中庭不使用实时阴影。
## 操作

| 按键 | 功能 |
| --- | --- |
| 空格 | 开始 / 停下后再次起飞 |
| W / I / ↑ | 爬升 |
| S / K / ↓ | 俯冲 |
| AD / JL / ← → | 左右转弯；停下时调整方向 |
| Shift | 按住加速 |
| Ctrl | 按住慢飞 |
| P / Esc | 暂停或继续 |
| R | 回到当前场景起点 |

飞机有前进动力，但不会自动保持高度。松开爬升后，机头平滑下沉至约 12° 的下降滑翔姿态；爬升按键采用非线性渐进响应：按下后先逐步抵消下沉，再缓慢爬高。全力爬升的机头仰角约 8°，室内不加速时稳定上升约 0.27 m/s，略低于自然下降速度的一半；短按不会猛抬头。爬升逐渐减速，俯冲仍会明显加速。教室默认滑翔稳定速度约 2.8 m/s、持续加速约 4.8 m/s，具体受姿态与加速/慢飞输入影响。室内转弯也更灵活。山谷保留较高旅行速度。

碰到课桌、墙面、玻璃、天花板、地面或山谷建筑、树木会停止。再起飞时沿碰撞表面向外留出距离；碰到墙壁会自动朝内重新抛出。切换窗口自动暂停，回来按 P 继续。

## 风与速度感

- **气流随速度增强**：慢飞时几乎没有，高速时连续出现，减速后平滑消散。每个气流节点在世界坐标中停留约 0.4 秒，不会作为固定彩带随飞机转动，也不再周期性闪断。本版根据最新反馈改为高速匀速时也保留气流。
- 镜头随速度扩大视野并轻微后拉，外围有径向模糊、拉伸和少量空气线，中心保持清楚。室内效果按室内速度范围计算，绝对速度降低仍然有加速感。
- “动感”可选标准、柔和或关闭；关闭镜头效果仍保留翼尖气流。省电和像素画质跳过扭曲与模糊，也关闭教室阴影。
- 风声的响度和音色随速度变化；减速变轻，落地只留很弱底声，暂停或关闭声音后渐静。默认开启，首次点击出发后播放。
- 固定 120 Hz 物理步，显示位置插值；镜头位置与朝向共用同一显示位置，避免两套追赶产生抖动。教室里的小物体不再让镜头突然缩近；使用对数深度缓冲，改善近距离纸飞机与远处山谷共存时的水面深度闪烁。

画质：均衡最高 1280×720，省电最高 960×540 / 30 FPS，清晰最高 1920×1080，像素最高 480×270 / 30 FPS。均衡与清晰跟随屏幕刷新，实际帧率受设备、窗口、供电和温度影响。

## 开发与范围

2026-09-11 光照调整：五层迷境主体和弯道使用 Three.js 自带 Lambert 材质，减少环境填充光，让顶面、侧面和背面产生明暗。夜色主题保留少量自发光；地面接触暗部在生成场景时写入原有顶点颜色，不增加实时阴影、叠加平面或全屏 AO。山谷和三重中庭同步调整环境光与方向光比例。模型开放素材候选及导入说明见 [开放模型素材.md](开放模型素材.md)。

迷境隧道不再按飞机高度整组隐藏，交由常规视锥裁剪处理；相机远裁剪和远雾按当前随机地图包围范围计算。楼板底面使用下层天空色的无光照材质，楼板独立于上层装饰的显示条件，保留实体碰撞。主体建筑仍接受方向光。

- `game.js`：控制、碰撞、镜头、声音、场景切换和 UI。
- `classroom.js` / `valley.js`：原有两个场景的程序化模型。
- `atrium.js` / `atrium-layout.js`：三层中庭模型、确定性随机布局和升层气流。
- `paper.js`：纸飞机模型与三种皮肤；笔迹和图形由 Canvas 绘制。
- `flight-core.js`：飞行、地形和气流强度计算。
- `flight-effects.js`：世界坐标气流与轻量画面效果。
- `check.cjs`：运行 `node check.cjs` 验证飞行规则和插值等。
- `check-atrium.cjs`：运行 `node check-atrium.cjs` 验证 100 个布局种子、通道净空、楼板、中庭开口、气流及可穿越圆环。
- `preview.cjs`：可选本地服务器，用 `node preview.cjs` 启动。

这是街机式原型，不是真实空气动力学仿真。碰撞使用机头、翼尖、机腹等点的运动扫掠；教室物品使用近似盒体，山谷建筑使用几何表面，树木使用近似轮廓。吊扇采用固定包围盒，山谷风车叶片不参与碰撞。尚无手机触控或飞行进度存档。
